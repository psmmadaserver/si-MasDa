# Si MasDA — Tabler UI Preview

Paket ini berisi frontend Tabler untuk pratinjau dan deployment terpisah. Paket ini BELUM terhubung ke backend Google Apps Script atau Google Sheets dan bukan pengganti aplikasi produksi.

## Deploy di Vercel
- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`

Kode sumber backend asli dan HTML lama sengaja tidak disertakan dalam paket frontend ini. Jangan menaruh kata sandi, token API, token WhatsApp, atau rahasia lain di repositori frontend.
