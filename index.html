STATUS PERANGKAT WAMEMERIKSA...

Scan Barcode QR WhatsApp
Tautkan nomor WhatsApp pengirim

Simpan token API Fonnte terlebih dahulu pada tab Template Pesan & Uji Coba, kemudian tekan tombol Tampilkan Kode QR WhatsApp.

Buka Dashboard Fonnte
Panduan Menautkan WhatsApp Sekolah
  1. Buka dashboard provider WhatsApp dan masuk ke akun sekolah.
  2. Tautkan perangkat/nomor pengirim sesuai instruksi provider (misalnya dengan scan QR di dashboard).
  3. Salin token API provider dan simpan pada tab Template Pesan & Uji Coba.
  4. Isi nomor WhatsApp wali siswa di Data Master → Master Siswa.
  5. Uji pengiriman sebelum menggunakan notifikasi otomatis.
Cara kerja otomatis:
Setelah siswa melakukan absensi masuk/pulang, Si MasDA mengirim pesan ke nomor wali melalui API jika token aktif dan nomor wali tersedia.
